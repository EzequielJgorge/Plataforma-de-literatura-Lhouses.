# Plataforma de Escritura Creativa y Literatura 📝✨

Este proyecto es un espacio digital diseñado para la publicación, organización y lectura de textos literarios y contenido creativo. Su propósito es ofrecer a escritores y lectores una interfaz limpia, cómoda y enfocada en la lectura, optimizada para funcionar en cualquier dispositivo.

## 🛠️ Tecnologías Utilizadas

* **Frontend:** HTML5, CSS3, JavaScript
* **Diseño y Estilos:** Responsive Design (Adaptable a celulares y computadoras)
* **Control de Versiones:** GitHub

## 💻 Características Principales

* **Biblioteca de Textos:** Organización clara de relatos, poemas o artículos literarios.
* **Modo Lectura:** Diseño visual descansado y minimalista para priorizar los textos.
* **Navegación Fluida:** Interfaz intuitiva para explorar las distintas categorías de escritura.
